# Quickstart Verification Guide: 前端系统总布局规划

**Feature Branch**: `001-frontend-main-layout`
**Date**: 2026-08-16
**Spec**: [spec.md](spec.md)

## Prerequisites

- Node.js >= 18
- frontend 开发服务正运行于 `http://localhost:5174` (或 Vite 开发服务器)

## Manual Verification Steps

1. **总布局页面就绪校验**
   - 启动 frontend 开发服务器 (`npm run dev` in `frontend/`)
   - 在浏览器访问 `http://localhost:5174`
   - **预期效果**: 页面呈现极致简洁的飞书云文档三栏/双栏总布局。左侧侧边栏、顶部面包屑与操作栏、中央主工作区卡片比例和谐无错位。

2. **侧边栏折叠/展开校验**
   - 点击左侧边栏底部的折叠控制按钮
   - **预期效果**: 侧边栏平滑收起至 64px 宽度图标栏，主工作区自动扩充填满；再次点击可平滑展开至 260px，折叠状态在刷新后从 LocalStorage 自动恢复。

3. **导航树与面包屑联动校验**
   - 在左侧知识库目录树中展开 `影视` 目录并点击 `电影` 节点
   - **预期效果**: 顶部面包屑更新为 `工作空间 > 影视 > 电影`，主工作区标题更新为 `电影`，并载入对应文档/卡片。

4. **主工作区多组件自适应校验**
   - 在树节点中切换点击文档节点（`type: 'doc'`）与 Draw.io 图表节点（`type: 'chart'`）
   - **预期效果**: 主工作区统一保持包含标题与元信息头的容器结构，无缝渲染对应的 `my-doc-editor` 编辑器或 `Draw.io` 离线画布。

5. **无缝主题切换校验**
   - 点击顶部栏的主题切换按钮
   - **预期效果**: 界面在浅灰高质感调性与暗黑沉浸调性之间流畅平滑过渡，无样式破裂或文字不可见问题。
